# 为什么做 quotestack

> quotestack 设计决议 · 第 0 部分 · v0.8（2026-11-07）
> 返回索引 → [README](README.md)

开源项目必须回答一个问题：**已经有 akshare、tushare、yfinance 了，为什么还要你？**

本文是这个问题的答案。

---

## 1. 起因：一个真实的资产管理场景

个人投资者（包括本项目的作者）的资产构成通常是：

```
基金（大头，多为场外）
  + 股票（A股、少量美股）
  + 加密货币（少量）
```

要在一个看板里把它们汇总成「总市值 / 盈亏 / 净值曲线」，需要同时解决四类数据源的差异。而现有工具要么只覆盖其中一两类，要么返回形态五花八门，每接一个源都要重写一遍解析、缓存和降级。

**quotestack 的目标很窄**：把这四类资产的数据源，收敛成一套一致的调用方式。

---

## 2. 现有方案的实际缺口

以 2026-11 抓取到的包元数据为准：

| 项目 | 核心依赖数 | 覆盖范围 | 返回形态 | 门槛 |
|---|---|---|---|---|
| **akshare** | 13（pandas、lxml、bs4…） | 极广，几乎一切 | DataFrame，接口各异 | 免注册 |
| **tushare** | 7 | A股为主 | DataFrame | **需 token + 积分** |
| **yfinance** | 11（pandas、numpy…） | 仅 Yahoo | DataFrame | 免注册 |
| **easyquotation** | 3 | 仅 A股实时 | dict | 免注册 |
| **adata** | 4 | A股为主 | DataFrame | 免注册 |
| **quotestack** | **2**（httpx、pydantic） | A股 / 美股 / 场外基金 / 加密 | **统一模型** | 免注册 |

数字说明的是取舍方向，不是优劣：`akshare` 用 13 个依赖换来了极广的覆盖，这是合理的。

> 依赖数为镜像源抓取时的版本，官方源可能略有滞后差异；比较的是**量级**，不是精确值。

### 真正的缺口在四个地方

**① 返回形态不统一**

`akshare` 每个接口返回一个 DataFrame，列名、索引、单位各不相同。要用起来，调用方得为每个接口写一层适配——而这层适配，恰恰是可以复用的。

**② 没有可处置的错误语义**

调用方拿到的通常是裸 `Exception` 或空 DataFrame，无法区分：

- 代码不存在
- 源暂时挂了
- 该品种本来就没有这个数据
- 返回结构变了（需要升级库）

这四种情况的处置方式完全不同（换参数 / 重试 / 换接口 / 报 bug），但调用方只能一律 `try/except`。

**③ 缓存与降级要自己写**

对外部数据源的缓存、并发去重、失败兜底、限流，是一个反复出现的工程问题。每个接入方都要重新解决一遍，而且通常会漏掉"过期数据该不该丢弃"这类细节。

**④ 场外基金链路薄弱**

多数库把重心放在股票行情。场外基金（占个人资产的大头）需要的是：净值曲线 + 基金画像 + 季度持仓 + 业绩基准，这套链路在开源生态里几乎是空白。

---

## 3. 我们的取舍

**不追求覆盖广，追求用起来省心。**

| 我们做 | 我们不做 |
|---|---|
| 统一模型（10 个方法，一致的返回结构） | 覆盖所有市场、所有品种 |
| 类型安全（mypy strict + `py.typed`） | 数据仓库 / 存储服务 |
| 可处置的错误（10 类，各有处置策略） | 量化回测框架 |
| 内置缓存 / 单飞 / 降级 / 限流 | 交易下单 |
| 场外基金完整链路（净值 / 画像 / 持仓 / 基准 / 估值） | 机构级数据质量保证 |

---

## 4. 什么时候不该用 quotestack

诚实地划出边界：

| 你的需求 | 更合适的选择 |
|---|---|
| 需要 A股全品种（可转债、期货、期权、龙虎榜…） | `akshare` |
| 需要分钟级长历史做回测 | 专业数据服务（分钟线只回溯约 1 个月） |
| 需要机构级数据质量与 SLA | 付费数据源 |
| 需要财报、宏观、行业数据 | `tushare` / `akshare` |
| 只要美股，且能访问 Yahoo | `yfinance` |
| 只要 A股实时报价 | `easyquotation`（更轻） |

---

## 5. 差异化价值主张（三句话）

1. **统一**——四个市场、十条数据链路，一套模型、一种错误语义。
2. **省心**——缓存、降级、限流、并发去重都已内置，不用自己造。
3. **懂基金**——场外基金的净值、画像、持仓、基准、估值，是别处找不到的完整链路。

---

## 6. 与 AssetPilot 的关系

quotestack 最初是为个人资产看板 [AssetPilot](https://github.com/whyxian) 抽出来的数据层。

抽出来的动机很实际：**任何做个人资产管理的人，都会遇到同一套数据源问题**。与其在每个项目里重写一遍，不如把它做成一个独立、可复用、可被审视的库。

它保持零内部依赖，即使 AssetPilot 不存在了，quotestack 依然可以独立存在。

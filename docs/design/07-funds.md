| 基金 | 类型 | 股票占净比 |
|---|---|---|
| 022430 华夏中证A500ETF**联接**A | ETF 联接 | 1.91% ~ 2.73% |
| 012733 易方达中证人工智能ETF**联接**A | ETF 联接 | 1.34% ~ 2.24% |

联接基金 90%+ 的资产是**目标 ETF**，不是股票。用「股票仓位」做系数会算出接近 0 的估值。

## 2. 估值公式

### 2.1 指数型 / ETF 联接

```
估算涨跌 = 跟踪标的指数实时涨跌 × (100% − 现金% − 债券%)
```

系数实测约 **91.7%**（022430）。

### 2.2 主动型

```
估算涨跌 = Σ(前十大权重 × 个股实时涨跌)
         + 剩余仓位 × 权益基准指数涨跌
```

### 2.3 剩余仓位怎么补

**剩余仓位 = 100% − 现金% − 债券% − 前十大权重合计**

补法：按业绩基准中**权益类组件**的权重归一后加权。

```
166002 基准 = 中证800×70% + 上证国债×25% + 存款×5%
权益类只有 中证800（70%）→ 归一后 100%
剩余仓位（约 18%）全部按 中证800 涨跌补
```

多权益组件时：

```
110011 基准 = 沪深300×50% + 中证香港300×30% + 中债×20%
权益类合计 80% → 归一：沪深300 62.5%，港股 37.5%
```

### 2.4 权益类判定

三步规则，零维护：

```
1. 命中非权益关键词              → 非权益
2. 名字含「指数」                → 权益
3. 两者都不命中                  → 未识别 → 按非权益处理（保守）
```

**非权益关键词**

| 类别 | 关键词 |
|---|---|
| 债券 | `债`、`存单`、`短融`、`票据`、`回购` |
| 现金 | `存款`、`利率`、`货币` |

**为什么用「含指数」而不是白名单**

| 组件 | 白名单方案 | 「含指数」规则 |
|---|---|---|
| 中证港股通综合指数 | 需手工添加 | 自动识别 |
| 中证高端装备制造指数 | 需手工添加 | 自动识别 |
| 新出现的细分指数 | 持续漏判 | 自动适配 |
| 维护成本 | 持续 | 零 |

债券类指数的名字必然带「债」「存单」「短融」等词，所以先判非权益不会被漏。

**实测验证（20 个真实基准组件全部正确）**

| 组件 | 判定 |
|---|---|
| 中证800 / 中证800成长 / 沪深300 / 中证A500 | 权益 |
| 中证高端装备制造 / 中证人工智能主题 | 权益 |
| 中证港股通综合 / 恒生指数 / 中证香港300 | 权益 |
| 纳斯达克100（经汇率调整） | 权益 |
| 上证国债 / 中债总 / 中债-综合全价 / 中证综合债 | 非权益 |
| 一年期定期存款基准利率 / 活期存款利率 / 七天通知存款利率 | 非权益 |

**已知误判风险**：像「中证资产支持证券指数」这类既不带「债」又带「指数」的债券类会被判为权益。这类在基金基准中极罕见。

**必须暴露判定结果**

```json
"benchmark_assumption": {
  "equity": ["中证800"],
  "non_equity": ["上证国债", "一年期定期存款基准利率"],
  "unclassified": []
}
```

`unclassified` 非空即说明出现了规则覆盖不到的名字，需要补充关键词。

### 2.5 货币基金不做估值

货币基金（`货币型-*`）净值恒为 **1.0**，估值没有意义，且其基准通常是存款利率，不含任何权益组件。

```
profile.fund_type 以「货币型」开头
  → estimate 直接返回 basis="none", change_pct=0
  → explanation: "货币基金净值固定，不做估值"
```

---

### 2.6 完整流程

```
1. 拉 profile
   ├─ 货币型            → basis=none, change=0（结束）
   ├─ 指数型 + 跟踪标的   → 公式 A
   └─ 其他（主动型）      → 公式 B

公式 A（指数型 / ETF 联接）
   change = 跟踪指数实时涨跌 × (100% − 现金% − 债券%)

公式 B（主动型）
   change = Σ(前十大权重 × 个股实时涨跌)
          + 剩余仓位 × 权益基准加权涨跌

兜底（两公式通用）
   组件无数据          → 剔除该组件，其余重新归一
   全部失效            → basis=none
   输入超出 max_stale  → basis=none（不抛错）
   输出固定携带         → basis / coverage / benchmark_assumption / explanation
```

## 3. 缺失与降级

- 还原不了的组件按 **0** 计入
- 必须带 `basis`（`index` / `holdings` / `none`）与 `coverage`
- 必须带 `explanation` 人话说明

```json
"estimated": {
  "change_pct": -1.61,
  "basis": "index",
  "coverage": 0.917,
  "as_of": "2026-09-30",
  "explanation": "指数型：跟踪「中证A500」实时涨跌 -1.76% × 非现金债券资产占比 91.7% = -1.61%"
}
```

### 3.1 输入过期时降级，不抛错

估值的输入各有生命周期：

| 输入 | 缓存 | 过期上限 |
|---|---|---|
| `profile` | 24 小时 | 7 天 |
| `holdings` | 永久 | 无 |
| `quote` | 30 秒 | 1 天 |
| **`estimate` 自身** | 30 秒 | **5 分钟** |

任一输入超出其过期上限时，**不抛异常**，降级为 `basis: "none"`：

```json
{
  "change_pct": null,
  "basis": "none",
  "reason": "input_stale",
  "stale_inputs": ["profile(age=8d)"],
  "explanation": "基金画像已 8 天未更新，超过 7 天上限，估值不可用"
}
```

**`change_pct` 用 `null` 而不是 `0`。** 「算不出来」和「没涨没跌」是两件事：
填 0 会让前端显示成「持平 0.00%」，把未知伪装成事实。

**只有货币基金返回 `0`**——它的净值恒为 1.0，那是真正的零变化，不是未知。

**理由**：估值本来就是「尽力而为的参考值」，不是事实。拿不到可靠输入时说「算不出来」比抛异常更合适——客户端本来就要判断要不要显示。

**同时，原始数据已由 `profile` / `holdings` / `nav` 单独返回**，调用方若觉得库的估值口径不合理，完全可以用原始数据自行计算。

## 4. 业绩基准

### 4.1 解析

- 基准字符串 → 组件列表：`{指数名, 权重, 是否可还原}`
- 可还原：中证800→`000906`、沪深300→`000300`、中证A500→`000510`、上证国债→`000012`
- 不可还原：中债系列指数、存款利率

### 4.2 曲线合成与对齐

多指数起始日不同（如中证800 自 2005、中证香港300 更晚）时：

```
1. 区间内完全无数据的组件 → 剔除，其余权重重新归一
2. 实际起点 = max(请求 start, 所有参与组件的最早可用日)
3. 输出 effective_start，调用方知道曲线从哪天开始
4. 不做前向填充——缺就是缺，不编造
```

返回：

```json
{
  "effective_start": "2010-03-01",
  "components_used": ["沪深300", "中证香港300"],
  "components_dropped": ["中债总指数"],
  "coverage": 0.80,
  "series": [{"date": "2010-03-01", "value": 1.0}, ...]
}
```

**为什么不做前向填充**：填充会让曲线在停牌或数据缺失期间假装有值，比缺一段更危险。

曲线起点归一为 **1**，与基金净值曲线可直接同图对比。

## 5. 历史季度持仓

- 一次请求返回整年 4 个季度（约 20 KB）
- 可回溯到基金成立（166002 实测到 2010）
- 已取过的季度**永久缓存**（历史不可变）

### 5.1 分页契约

```json
{
  "quarters": [
    { "quarter": "2026Q3", "as_of": "2026-09-30", "holdings": [...] },
    { "quarter": "2026Q2", "as_of": "2026-06-30", "holdings": [...] }
  ],
  "has_more": true,
  "next_before": "2026Q1"
}
```

| 参数 | 语义 |
|---|---|
| 不传 `before` | 返回**最新** `limit` 个季度 |
| 传 `before="2026Q2"` | 返回**严格早于** 2026Q2 的季度（排他游标） |
| `limit` | **季度数**，不是行数 |
| 到底 | `has_more=false`，`next_before=null` |

排序固定**倒序**（最新在前）。

## 6. 估值精度立场

- 可回测：净值历史 + 历史季度持仓 + 指数历史都齐备
- 脚本：`benchmarks/estimate_accuracy.py`，输出相关系数与 MAE
- 预期量级：指数型 corr > 0.9 / MAE < 0.3%；主动型 corr 0.6–0.8 / MAE 0.5–1%
- **不作 CI 门槛**（数据会变，卡死会天天红）
- 立场：估值是「盘中知道大概在涨还是跌」，不是「预测净值」

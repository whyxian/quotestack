## 一、项目与流程

| 术语 | 全称 / 含义 | 在本项目中的意思 |
|---|---|---|
| **MVP** | Minimum Viable Product | 最小可用版本。先做一个能跑通的最小子集，用来验证设计 |
| **CI** | Continuous Integration | 持续集成。每次提交自动跑 lint、类型检查、测试 |
| **PR** | Pull Request | 合并请求 |
| **fixture** | — | 录制下来的真实响应样本，供测试离线回放 |
| **golden test** | 金样本测试 | 把解析结果存成基准文件，逐字比对，改动立刻可见 |
| **LTS** | Long Term Support | 长期支持版本 |

## 二、行情与数据结构

| 术语 | 含义 |
|---|---|
| **OHLCV** | Open / High / Low / Close / Volume，即开盘、最高、最低、收盘、成交量 |
| **K 线 / bar** | 一根 K 线。interval 可以是 `1m`…`60m`、`1d`、`1w`、`1M` |
| **秒级 tick** | 逐笔成交。**本项目不提供**，只到分钟线 |
| **TTL** | Time To Live，缓存存活时间。超过即视为过期 |
| **stale** | 陈旧。缓存过期但回源失败时，仍返回旧值并标记 `stale: true` |
| **coverage** | 覆盖率。表示"有多大比例的数据参与了计算"，如估值只覆盖了 91.7% 的资产 |
| **derived** | 派生的。由其他数据计算得到，非源直接提供（如交叉汇率、估值） |

## 三、复权

| 术语 | 含义 |
|---|---|
| **不复权**（`none`） | 原始成交价。**算钱用这个** |
| **前复权**（`qfq`） | 以最新价为基准向前调整，历史价格连续。**看图用这个** |
| **后复权**（`hfq`） | 以上市首日为基准向后调整，长期收益对比用 |
| **除权除息** | 分红、送股导致股价跳空。不复权的 K 线会出现断崖，这是正常的 |

## 四、金融品种

| 术语 | 含义 |
|---|---|
| **场内 / 场外** | 场内 = 交易所挂牌（有 K 线）；场外 = 基金公司直销/代销（只有每日净值） |
| **ETF** | 交易所交易基金，场内交易，有 K 线 |
| **LOF** | 上市开放式基金，可场内也可场外 |
| **QDII** | 合格境内机构投资者基金，投资境外市场，有交易时差 |
| **联接基金** | 专门买某只 ETF 的基金。**90%+ 资产是目标 ETF，直接持股很少** |
| **净值（NAV）** | Net Asset Value，基金每份的实际价值。场外基金每日公布一次 |
| **估值（estimate）** | 用持仓和指数实时涨跌**推算**的当日净值变化。是参考值，不是事实 |
| **跟踪标的** | 指数基金所跟踪的指数，如"中证A500指数" |
| **业绩比较基准** | 基金给自己定的参照标准，如"中证800×70% + 国债×25% + 存款×5%" |

## 五、本项目专有

| 术语 | 含义 |
|---|---|
| **instrument（标的）** | 一个可交易对象的抽象，由 `asset_class + market + code` 唯一确定 |
| **三元组** | 即 `(asset_class, market, ticker)`。因为 `000001` 既是股票也是基金，必须三者齐备才能定位 |
| **secid** | 东方财富的标的标识，形如 `1.600519`（1=沪、0=深、105/106/107=美股） |
| **能力矩阵** | 标的能力与源能力的交集决定"这次能不能拿到数据" |
| **三态降级** | 行情状态的三种取值：`REALTIME`（实时）、`HISTORICAL`（历史兜底）、`UNAVAILABLE`（不可用） |
| **单飞 / single-flight** | 多个并发请求同时发现缓存过期时，只放一个去回源，其余等它的结果 |
| **冷却 / cooldown** | 某源连续失败后，短时间内直接跳过它，避免每次请求都白等超时。极简版熔断 |
| **兜底 / fallback** | 首选源失败时自动换下一个源 |
| **幂等** | 同一操作重复执行，结果相同。如重复收藏同一自选股不产生重复记录 |
| **游标 / cursor** | 分页的定位标记。本项目用排他游标，如 `before=2025Q4` 表示"严格早于 2025Q4" |

## 六、技术

| 术语 | 含义 |
|---|---|
| **async / await** | Python 异步语法。本项目所有 I/O 方法都是异步的 |
| **事件循环** | asyncio 的运行核心。同步包装会在后台线程常驻一个 |
| **Protocol** | Python 的结构化类型协议。类只要实现了方法就算"符合"，无需继承 |
| **USD base** | 以美元为基准的汇率表。任意两币种通过 USD 交叉换算 |
| **交叉汇率** | 由两个 USD 汇率相除得到的汇率，如 EUR→CNY = (USD→CNY) ÷ (USD→EUR) |
| **schema** | 数据结构定义。`SchemaChanged` 表示上游返回结构与预期不符 |
| **SSE** | Server-Sent Events，服务端推送流。用于未来的对话式交互，与本库无直接关系 |

## 七、文件与配置

| 术语 | 含义 |
|---|---|
| **pyproject.toml** | Python 项目的标准配置文件，声明依赖、构建方式、工具配置 |
| **py.typed** | 空文件，标记该包自带类型信息，供 mypy 识别 |
| **extra** | 可选依赖组，如 `quotestack[browser]` 只装 Playwright。避免让所有人承担重依赖 |
| **hatchling** | 本项目选用的构建后端 |

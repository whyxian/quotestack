# 定位与边界

> quotestack 设计决议 · 第 1 部分 · v0.8（2026-11-07）

> **实现状态**：🚧 部分实现：M1 已完成其中 3 个方法


## 定位

**面向 A股 / 美股 / 场外基金 / 加密 的多源适配层。**

不追求"覆盖所有市场"，只做小而美：把这几类资产的数据源差异收敛成一套一致的调用方式。

**为什么是这个范围**

个人资产管理的真实构成就是「基金 + 股票 + 少量加密货币」。场外基金恰恰是现有开源库普遍薄弱的环节（多数只做股票行情），因此它是本项目的特色能力。

**价值在于屏蔽三件事**

1. 源之间的差异（格式、编码、复权、时区、标识体系）
2. 源的易变性（改版只改一个 adapter）
3. 源的能力差异（谁有 K 线、谁只有净值、谁要后缀）

**不是竞品替代**：不试图覆盖全市场、全品种，也不做数据仓库。需要更广覆盖时，`akshare` 等更合适。

**基本参数**

| 项 | 决议 |
|---|---|
| 包名 | `quotestack` |
| 许可 | MIT |
| 形态 | Python 库 + 可选 FastAPI 薄壳 |
| 仓库 | 先置于 AssetPilot monorepo，但**零内部依赖**，随时可独立 |

## 边界：三层，单向依赖

```
┌─ 身份层 ──────────────────────────────┐
│ resolve                               │  只做 code → 各源标识
└───────────────────────────────────────┘
              ↓
┌─ 取数层：一对一映射到某个源能力 ────────┐
│ quote / quote_many / history          │
│ nav / profile / holdings / fx         │
└───────────────────────────────────────┘
              ↓
┌─ 派生层：只依赖取数层，彼此不依赖 ───────┐
│ estimate / benchmark                  │
└───────────────────────────────────────┘
```

**明确不做**

| 不做 | 理由 |
|---|---|
| 算盈亏、收益率 | 业务口径，属于应用层 |
| 管持仓、交易、现金 | 业务实体 |
| 用户 / 权限 | 数据层不该有业务概念 |
| 选复权口径 | 由调用方传 `adjust` 参数 |
| 定义"什么算一天" | 由调用方决定时区视角 |
| 调度策略 | 由调用方决定何时调用 |

## 标识解析

调用方只传 `code + asset_class + market`，解析在服务内完成。

### 四级漏斗

| 级 | 手段 | 覆盖 | 需要网络 |
|---|---|---|---|
| 0 | 归一化（补零 / 大写 / 校验） | — | 否 |
| 1 | 规则推导（前缀 → secid） | 约 90% | 否 |
| 2 | 东财搜索 API 消歧 | 约 9% | 是 |
| 3 | 返回码 / 名称校验 | 可选 | 是 |

### 规则示例

| 输入 | 规则 | 推出 |
|---|---|---|
| `CN / STOCK / 600519` | 6 开头 → 沪 | `em: 1.600519`, `tx: sh600519` |
| `CN / STOCK / 000001` | 0 开头 → 深 | `em: 0.000001`, `tx: sz000001` |
| `CN / STOCK / 920000` | 92 开头 → 北交所 | `em: 0.920000`, `tx: bj920000` |
| `CN / FUND / 510010` | 场内沪（50/51/56/58） | `em: 1.510010`, `tx: sh510010` |
| `CN / FUND / 160105` | 场内深（15/16/18） | `em: 0.160105`, `tx: sz160105` |
| `CN / FUND / 022430` | 场外 | `tt: 022430`（无交易所标识） |
| `CRYPTO / CRYPTO / BTC` | 符号 | `binance: BTCUSDT` |

### 为什么不能靠前缀猜 secid

实测反例：

```
000001  → 1.000001 = 上证指数      0.000001 = 平安银行
160105  → 1.160105 = 19山东47(债券) 0.160105 = 南方积配LOF
```

同一个代码在不同市场下是完全不同的标的。`asset_class` 本身是消歧信息，但不足以覆盖全部情况（`160105` 在东财同时是债券和 LOF）。

**正确做法**：用东财搜索接口反查，返回 `QuoteID`：

```
searchapi.eastmoney.com/api/suggest/get?input=000001&type=14
→ 000001:2:深A:平安银行 | 000001:1:指数:上证指数 | 000001:6:基金:华夏成长混合
```

美股更简单：搜索结果直接给出 `QuoteID`（`105.AAPL` / `107.SPY`）。

### 基金代码前缀不可靠（实测修正）

最初按前缀判断场内/场外：

```
50/51/52/56/58 → 沪  15/16/18 → 深  其余 → 场外
```

实测发现 **`166002`（中欧新蓝筹混合A）是场外基金，但前缀是 `16`**——按规则会被误判成深市 LOF，导致 `nav` 报 `Unsupported`。

**修正后的规则**：

| 情况 | aliases | capabilities | confidence |
|---|---|---|---|
| 所有基金 | `tiantian` | `NAV` `PROFILE` | `exact` |
| 前缀像场内 | 再加 `eastmoney` `tencent` | 再加 `QUOTE` `HISTORY` | `partial` |

`partial` 的意思是：**前缀只是线索，不是证据**。调用方看到 `partial` 就知道该标的能力是"可能可用"，失败属正常。

如果后续某只基金实际不场内，`QUOTE` 会返回 `EmptyResponse`，路由自动降级，最终得到 `Unavailable`——不会静默给出错误数据。

### 关键决议

- **不内置品种目录**——目录归应用层（`asset_varieties` 45,970 条）
- **应用层也不存 aliases**——避免"两份真相"；源改标识体系时，服务缓存 7 天自愈，应用表会永久错
- `source_name` 是"源说它叫什么"，**不是权威名称**；权威名称在品种库
- `resolve(..., expected_name=None)` 可选传入，用于校验 secid 是否选错（`1.000001` 的代码也是 `000001`，仅靠代码校验发现不了它其实是上证指数）
- `confidence` 三值：`exact` / `inferred` / `partial`
- 歧义时抛 `Ambiguous`，带完整 `candidates` + `hint`

### 实测的名称不一致

| 代码 | 品种库 | 东财 | 腾讯 |
|---|---|---|---|
| 600519 | 贵州茅台 | 贵州茅台 | 贵州茅台 |
| 000001 | 平安银行 | 上证指数 | 上证指数 |
| 160105 | 南方积极配置混合(LOF) | 19山东47 | 南方积配LOF |
| 920000 | 安徽凤凰 | 安徽凤凰 | — |

结论：**身份只认 `code + class + market`，name 绝不参与判定。**

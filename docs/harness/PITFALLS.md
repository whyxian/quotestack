# 已知陷阱

每一条都来自真实踩坑。共同点：**写错不报错，只是数据悄悄错**。

---

## 数据源

| 陷阱 | 真相 | 后果 |
|---|---|---|
| 东财价格是放大整数 | 小数位在 `f1`（股票 2、ETF/美股 3），除以 `10^f1` | 统一按 ÷100，ETF 差 10 倍 |
| 东财涨跌幅单位固定 | `f3` 恒为 0.01%，**与 `f1` 无关**，除以 100 | 按 `10^f1` 缩放，美股错 10 倍 |
| 东财 K 线是 O-C-H-L | `date, open, close, high, low, volume` | 按 OHLC 解析，high/low 互换 |
| 东财列表分页上限 | `pz` 最大 100，传更大只是返回 100 | 用"这页不满"判断结束会截断到 100 条 |
| 东财无价格返回 `"-"` | 是字符串，**truthy** | `not row.get("f2")` 过滤不掉任何东西 |
| 514 是防爬码 | 非标准 HTTP，4 req/s 通过、5 req/s 触发 | 触发后同连接持续被拒 |
| 腾讯返回 GBK | 必须 `content.decode("gbk")` | 中文乱码 |
| 腾讯 A股/美股布局不同 | 标志位 `1` / `200`，时间格式与时区也不同 | 统一解析会错位 |
| 美股时区是纽约 | 时间戳按 `America/New_York` 解析 | 按东八区差 13 小时 |
| 天天基金列表带 BOM | 用 `utf-8-sig` 读 | 正则匹配失败 |
| 天天基金 `var r` 不是 JSON | 先正则提取再 `json.loads` | 直接解析失败 |
| 天天基金画像缺 `</td>` | `<td>xxx（前端）<th>基金类型</th>` | `<th>…</th><td>…</td>` 会吞掉下一个字段 |
| 天天基金占位符 | `'---'` 和 `"该基金暂未披露业绩比较基准"` | 当真实值用，或解析成基准组件 |

## 业务语义

| 陷阱 | 真相 |
|---|---|
| `000001` 二义性 | 既是平安银行（STOCK）也是华夏成长混合（FUND），必须三元组定位 |
| 基金代码前缀不可靠 | `166002` 是场外基金但前缀 `16` 通常意味着深市 LOF |
| ETF 联接基金 | 股票占净比只有 ~2%，90%+ 是目标 ETF。权益敞口要算 `股票 + 其他` |
| 中债指数不可得 | 基准里的「中债系列」东财拿不到，按非权益处理并降 `coverage` |
| 场外基金无 K 线 | 只有每日净值，`history` 应抛 `Unsupported`，不是空数组 |
| 季报有发布延迟 | 回测必须滞后约 20 天才启用某季持仓，否则是未来函数 |
| 货币基金无持仓 | 返回空列表，不是错误 |
| 未知基金分类 | 一律 `OTHER`，**绝不猜成 EQUITY**——猜错等于算错估值 |

## 类型与时区

| 陷阱 | 真相 |
|---|---|
| `date` vs `ts` | K 线的 `date` 是交易日（无时区）；报价的 `ts` 是带偏移的时刻。不许混用 |
| `bool` 是 `int` 的子类 | `isinstance(True, int)` 为真，端口校验会放行 `port = true` |
| `Decimal` 精度 | 金额累加全程 `Decimal`，中途转 `float` 会丢精度 |

## 文档与流程

| 陷阱 | 真相 |
|---|---|
| 手写数字会过期 | 方法数/路由数/错误数曾出现 4 种说法。现在由 `scripts/sync_docs.py` 生成 |
| 手写 OpenAPI 会漂移 | `docs/api/openapi.yaml` 是生成物，改接口后必须重新 dump |
| 实现了但不声明能力 | 源有 `list_instruments` 却没声明 `LIST`，health 报告会说谎 |
| 声明了但没实现 | 反向同理，`test_docs.py` 双向检查 |
